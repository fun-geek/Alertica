# ALERTICA - Emergency Alert System

ALERTICA is a comprehensive emergency alert system designed to provide timely notifications and critical information during emergencies. The platform enables authorities to send targeted alerts to citizens based on location, severity, and type of emergency.

## Features

### Precision Targeting
- **Dynamic Geofencing**: Target alerts to specific geographic areas
- **Personal Location Saving**: Users can save multiple locations for receiving relevant alerts

### Enhanced Communication
- **Structured Alert Templates**: Pre-defined templates for different emergency types
- **Multilingual Support**: Alerts available in multiple languages

### Two-Way Interaction
- **"I am Safe" Button**: Allow citizens to mark themselves as safe during emergencies
- **Citizen Reporting**: Enable users to report emergencies or provide feedback

### Advanced Admin Controls
- **Admin Dashboard**: Comprehensive dashboard for managing alerts and users
- **User Role Management**: Different permission levels (admin, creator, approver)
- **Post-Alert Analytics**: Track alert effectiveness and engagement

### Visual Enhancements
- **Live Background Effects**: Dynamic visual effects based on alert type (weather, fire, flood, etc.)

## Getting Started

### Prerequisites
- Python 3.8+
- Flask
- Other dependencies listed in requirements.txt

### Installation
1. Clone the repository
```
git clone https://github.com/Skull-boy/Alertica.git
```

2. Install dependencies
```
pip install -r "Main py/requirements.txt"
```

3. Run the application
```
python "Main py/app.py"
```

## Usage
1. Register as an organization or citizen .
2. Login to access the dashboard .
3. Create and send alerts (organization users) .
4. View and respond to alerts (citizens) .
